# wang-guangxin.github.io

Personal academic homepage built with **Vue 3 + Vite**, deployed to GitHub Pages.

## Tech Stack

- [Vue 3](https://vuejs.org) — UI framework
- [Vite](https://vitejs.dev) — build tool
- Python — uptime monitoring script

## Project Structure

```
├── src/
│   ├── App.vue              # Main app shell (nav, routing, theme)
│   ├── main.js              # Entry point
│   ├── style.css            # Global styles (CSS variables, dark mode)
│   ├── components/
│   │   └── SideCard.vue     # Profile sidebar card
│   └── views/
│       ├── HomeView.vue     # Home page
│       ├── PublicationsView.vue  # Papers & patents
│       ├── AboutView.vue    # Education & work timeline
│       └── SitesView.vue    # Site status monitoring
├── static/                  # Static assets (copied to build output)
│   ├── img/                 # Images
│   └── sites-data.json      # Generated by uptime.py
├── sites.json               # Site list config for uptime monitor
├── uptime.py                # Uptime/SSL monitoring script
├── data.csv                 # Uptime history (auto-generated)
├── build.sh                 # Full build script
└── vite.config.js
```

## Uptime Monitoring

The `Sites` page shows live status of your websites. Configuration is simple:

1. Edit `sites.json` to add/remove sites:

```json
{
  "sites": [
    { "name": "Blog", "url": "https://wgxls.site", "badges": ["Public Access"] }
  ]
}
```

2. Run the monitor to generate data:

```bash
python3 uptime.py
```

This checks HTTP status & SSL expiry for each site, computes 7-day / 24h uptime
from `data.csv` history, and writes `static/sites-data.json` which the frontend
consumes.

Optional email notifications (via SMTP env vars):
`notice_host_server`, `notice_user`, `notice_pwd`, `notice_mail`, `notice_receiver`.

Notifications are sent when:
- A site's up/down status changes since the last run
- A site's SSL cert crosses into the warning zone (≤ 15 days remaining)

Set `NOTICE_ENABLED=0` to disable notifications.

## Deployment

GitHub Actions (`.github/workflows/main.yml`) runs on a schedule:
1. Runs `uptime.py` to refresh site status
2. Builds the Vue site
3. Deploys `./public` to GitHub Pages
